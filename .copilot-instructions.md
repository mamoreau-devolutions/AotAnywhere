# AotAnywhere development notes

AotAnywhere cross-compiles .NET NativeAOT by taking over the SDK's native link
step. It does not invoke CMake.

- `src/ClangToolchainVersion.props` pins the content-package versions.
- `eng/toolchain-artifacts.json` is the immutable source manifest for official
  LLVM distributions, the exceptional awakecoding macOS x64 artifact, and
  CBake Linux sysroots. Do not replace URLs or hashes with unpinned downloads.
- `eng/build-toolchain-content.ps1` downloads a named manifest artifact,
  verifies its SHA-256, prepares its content payload, and packs the corresponding
  NuGet package. `prepare-toolchain-payload.ps1` defines the package layout.
- `src/Crosscompile.targets` resolves Clang/LLD, sysroots, and the Windows
  cross-link bundle. `UseExternalClang=true` bypasses package resolution for
  development; a Linux external build also needs `AotAnywhereLinuxSysroot`.
- `src/DirectLink.targets` calls Clang/LLD for Linux and macOS. The managed
  `AotAnywhereWindowsLink` task writes MSVC arguments to an `lld-link` response
  file and adds MSVC/UCRT/Windows SDK library paths.
- `src/Sdk/Sdk.props` must keep the first-restore-visible content-package
  references in sync with `Crosscompile.targets`. Plain package references
  cannot introduce their own restore dependencies.
- The generated `src/apple-sysroot` stubs require macOS and Xcode to refresh.
  `libSystem.tbd` is generated from the .NET runtime-pack undefined symbols,
  not copied from Apple SDK files.

Run the MSBuild logic tests with:

```sh
dotnet run --project tests/AotAnywhere.MSBuild.Tests/AotAnywhere.MSBuild.Tests.csproj -c Release
```

For a Linux source-tree smoke test, install Clang and LLD, then run:

```sh
dotnet build src/tasks/AotAnywhere.Tasks/AotAnywhere.Tasks.csproj -c Release
dotnet publish test/Hello.csproj -r linux-x64 -c Release \
  -p:UseExternalClang=true -p:AotAnywhereLinuxSysroot=/
```
